Markdown → PDF

同期HTTPで変換

ファイルのバイト列をPOSTし、PDFを直接受け取ります。

POST /api/convert

POST/api/convert?filename=input.md

filenameは.md / .markdown / .zipの拡張子を含めます。Markdown本文はUTF-8で送ります。本文はmultipartではなくapplication/octet-streamの生データです。

curl --fail-with-body \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @input.md \
  'http://localhost:7075/api/convert?filename=input.md' \
  --output document.pdf

成功レスポンス

項目値
Status200 OK
Content-Typeapplication/pdf
Content-Disposition入力名を基にした.pdf
X-Page-Count生成PDFのページ数
X-Section-Count入力Markdown数（1）
X-Warning-Count近似・除外の警告数

Azureでの認証

Azure上ではx-functions-keyヘッダーを付けます。ローカルCore Toolsでは通常キーは不要です。

curl --fail-with-body \
  -H "x-functions-key: $FUNCTION_KEY" \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @input.zip \
  'https://<app>.azurewebsites.net/api/convert?filename=input.zip' \
  --output document.pdf

主なエラー

HTTPcode意味
400EMPTY_INPUT / MISSING_FILENAME入力またはファイル名がない
413INPUT_TOO_LARGE / INPUT_BYTES_LIMIT / PAGE_LIMIT / OUTPUT_BYTES_LIMIT設定上限を超えた
415UNSUPPORTED_FORMAT対象外の拡張子
422INVALID_ENCODING / INVALID_ARCHIVE / INVALID_DOCUMENTUTF-8・ZIP・Markdown入力が不正

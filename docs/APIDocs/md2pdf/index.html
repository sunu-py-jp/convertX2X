Markdown → PDF

概要と変換ルール

Markdownを検索可能な日本語PDFへ変換します。Java 21・CommonMark・PDFBoxで従量課金Functions上で動きます。

できること

同期HTTP

MarkdownまたはZIPを送り、PDFを受け取る。

非同期HTTP

ジョブを登録し、PDF・report・ZIPを取得する。

直接Queue

入力Blobを参照するJSONを外部システムから送る。

入力形式

入力内容
.md / .markdownUTF-8のMarkdown。画像はBase64データURIで埋め込み可能
.zipMarkdownと相対パスの画像をまとめたZIP

ZIPルートのdocument.mdを優先し、なければZIP内で唯一のMarkdownを使います。相対画像パスはMarkdownの位置を基準に解決します。Office → Markdownのdocument.mdとimages/を含むZIPも入力できます。

対応する構文

見出し、段落、太字・斜体、番号付き・番号なしリスト、GFM表、引用、コードブロック、インラインコード、リンク、水平線、画像に対応します。用紙に合わせて折り返し・改ページし、ページ番号を付けます。<!-- pagebreak -->で明示改ページできます。

画像

PNG・JPEG・GIF（先頭フレーム）・BMPを、ZIP内の相対パスまたはBase64データURIから取得します。外部URLへの通信やローカルPCの絶対パス読み込みは行いません。欠損・未対応・外部画像は代替ラベルにし、reportへ警告を記録します。

input.zip
├── document.md
└── images/diagram.png

Markdown: ![処理の流れ](images/diagram.png)

再現範囲

PDFは本文・表・画像を読みやすく再配置した正規化出力です。HTML/CSSの見た目は再現せず、HTMLは文字として表示します。Mermaidは図へ変換せずコードとして表示します。どちらもreportへ警告を記録します（改ページ命令は除く）。

出力

document.pdf
report.json

同期HTTPはPDFを直接返します。非同期と直接QueueはPDFとreportを保存します。reportには入力・PDFのSHA-256、形式、ページ数、警告が入ります。sectionKindはdocument、sectionCountは1です。

上限

段落・表・画像の個数に固定上限はありません。入力・出力バイト数、画像画素数、任意のPDFページ上限を設定します。ZIPは展開後合計にも入力バイト上限が適用されます。既定のページ上限は0（無制限）です。詳細は設定・上限を参照してください。

Playground

http://localhost:7075/api/playgroundでMarkdownの貼り付け、ファイル・ZIP選択、同期・非同期変換、PDFプレビューと保存ができます。

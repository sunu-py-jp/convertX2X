非同期HTTP・成果物取得

大きい文書はQueueで処理し、完了後にPDFを取得します。

非同期はCONVERSION_STORAGE_CONNECTION_STRINGまたはManaged IdentityのBlob/Queue設定がある場合だけ有効です。

ジョブ登録

POST/api/jobs?filename=input.md
curl --fail-with-body \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @input.md \
  'http://localhost:7075/api/jobs?filename=input.md'

202 Acceptedでjobと相対statusUrlを返し、Locationにも状態URLを設定します。

状態確認

GET/api/jobs/{id}

状態はqueued / running / succeeded / failedです。成功時はresultUrl / reportUrl / archiveUrlを返します。失敗時はerrorCode / errorMessageを確認します。

成果物

パス内容
/api/jobs/{id}/resultdocument.pdf
/api/jobs/{id}/reportreport.json
/api/jobs/{id}/archivePDFとreportを含むZIP

未完了は409 JOB_NOT_READY、存在しないIDは404 JOB_NOT_FOUNDです。保持期間を有効にし、成果物が削除済みなら410 JOB_RESULT_EXPIREDを返します。

再試行と公開

Queueメッセージは再配送されてもジョブIDで直列化します。PDFとreportをすべて保存してから成功状態を公開し、途中の試行は成果物URLに採用しません。

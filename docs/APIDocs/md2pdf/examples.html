Markdown → PDF

変換例

日本語の見出し、表、リスト、コード、改ページを含むサンプルです。

入力と出力

input.md

入力Markdown

document.pdf

検索可能な日本語PDF

report.json

ハッシュ、ページ数、警告

変換する

curl --fail-with-body \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @input.md \
  'http://localhost:7075/api/convert?filename=input.md' \
  --output document.pdf

相対パスの画像を含める

input.zip
├── document.md
└── images/diagram.png

Markdownに![処理の流れ](images/diagram.png)と書き、ZIP全体をfilename=input.zipで送ります。Office → Markdownの出力ZIPも、そのまま入力できます。ZIPルートにdocument.mdがない場合は、Markdownを1ファイルだけにしてください。

画像付きHTMLは入力ZIPで送信
このHTMLは同じフォルダのPNGを相対参照します。APIには、index.htmlとPNGをまとめた入力ZIPを送ってください。HTML単体では素材を取得できません。文字・枠・矢印は写真に焼き込まず、別の編集可能な要素として重ねています。生成プロンプトは資料用の別添で、API入力ZIPには含めていません。

元写真はPPTX内で共有し、拡縮・回転・反転・切り抜き・角丸等は画像の設定として保存します。ぼかしだけは、その写真に処理をかけたPNGとして保持し、reportへIMAGE_BLUR_APPLIEDを記録します。PPTX上で画像の配置・大きさ・差し替えは編集できますが、CSSのblur半径を変更する効果としては保存されません。上に重ねた文字・枠・矢印は別の編集可能な要素です。画像のskew・影・clip-path、親filter等の未対応範囲は利用ガイドを参照してください。

01背景・枠・文字を持つ3枚のカード。フェードと移動を組み合わせて時間差で登場同じカードの部品が一緒に動くことと、開始の遅延

この入力の変換結果は、ネイティブ項目6件と、固定した元のアニメーション指定4件です。4枚目の左は2つの指定を1つのタイムラインへまとめ、右は未対応の背景色変更を原因として移動も含めて固定しています。元の指定と変換結果はreportで確認できます。色・角丸はunsupported-properties、無限の浮遊はinfinite-animationとして記録します。円の浮遊は1周期の終端が開始位置と同じなので、固定後も開始位置に表示されます。同じ要素の複数指定は、対応するものだけを部分的に残さず、全体をまとめて動かすか固定するかを決めます。

自分の環境で試す

同じ入力HTMLは機能ディレクトリのexamples/にも置いています。CLIはHTTPと同じ変換処理を呼び出します。

cd functions/html2pptx
npm ci --ignore-scripts --no-audit --no-fund
npm run convert -- examples/organization-governance.html output/organization

出力先にpresentation.pptx、report.json、result.zipとHTMLのプレビューを保存します。PPTXのプレビュー画像や比較用PDFはAPIの標準出力には含まれません。

ピクセル比較の再生成には、Node.js 24、Python/Pillow、Java 21とPOI/PDFBox、LibreOfficeが必要です。これは開発時の比較用であり、Functionsの実行にはLibreOfficeを使いません。

node scripts/visual-compare.mjs examples/visual-fidelity.html output/comparison
# --renderer poi で参考用のPOI描画も指定可能
# --classpath-file /path/to/classpath.txt でJavaクラスパスを指定

対応要素・制約は機能概要、実行環境と上限は利用ガイドを参照してください。

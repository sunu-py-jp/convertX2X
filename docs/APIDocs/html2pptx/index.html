HTML → PowerPoint

HTMLの資料を、編集できるPowerPointへ。

静的HTMLの配置をブラウザーで計算し、文字・表・図形をPowerPointの要素として出力します。SVGの体制図や構成図も、図形・線・文字へ分解します。元からPNG・JPEGで用意した素材は画像として保持します。

HTML / HTM / ZIPPPTX + report同期HTTP / CLIFlex Consumption · 4 GB

何を編集できるか

変換処理は同じAzure Function App内で完結します。同梱したChromiumがHTMLの配置を計算し、その座標・文字・輪郭からPPTXを組み立てます。変換時にLLM、OCR、外部の変換サーバーは呼びません。比較画像の作成に使うLibreOffice等は開発用で、本番のFunctionsには必要ありません。

入力の要素PowerPointでの扱い
見出し・本文・部分装飾編集可能なテキスト。日本語、太字、色、サイズ、改行を配置に反映
HTMLの表表のセルとして保持。結合見出しを含む例を掲載
多角形・凹形・自由曲線・角丸図形名の対応一覧に依存せず、輪郭を編集可能なパスへ変換。CSSで作った三角・星・円も対象
直線・折れ線・曲線・矢印編集可能な線・パス・矢印の図形。片方向・両方向の矢印、任意の点線・破線を扱う
SVGの図中文字編集可能なテキストとして出力。SVG全体の画像とは区別
PNG / JPEG元バイト列を共有して画像として保持。拡縮・回転・反転・切り抜き・角丸・透明度を反映
画像自身のCSS blur(px)その画像だけをぼかしたPNGとして保持。位置・サイズ・差し替えは編集可能、ぼかし量は固定

ブラウザーのFlex/Gridによる配置は変換時の座標に固定します。PowerPointで編集した後に、HTMLと同じ自動レイアウトが働くわけではありません。矢印やSVGのパスは見た目の図形として編集できますが、PowerPointの自動接続や組織図の意味までは付与しません。

親要素を含む2D変形を合成し、回転や図形の斜体変形を反映します。文字はブラウザーが確定した行と書式ごとのテキストとして配置します。空のCSS疑似要素で描いた矢印や装飾も変換します。

画像・図形・文字の前後関係はDOM順、z-index、親のスタッキングコンテキストを考慮します。ぼかした写真に重ねた文字や枠も別の編集可能な要素です。ぼかしを画像に反映した場合は、reportへIMAGE_BLUR_APPLIEDを記録します。

HTMLの入力とスライド区切り

UTF-8の.html / .htmを送ります。CSSや画像を別ファイルにする場合は、ルートにindex.htmlまたはindex.htmを1つ置いたZIPへまとめます。複数スライドはdata-slideを付けた要素ごとに作成します。

<meta name="pptx-slide-width" content="1280">
<meta name="pptx-slide-height" content="720">
<section data-slide>
  <h1>上期の業績</h1>
  <p>売上高は前年同期比12.6%増加しました。</p>
</section>
<section data-slide>
  <h1>下期の重点施策</h1>
</section>

区切りがなければ本文全体を1枚にします。既定寸法は1280×720 CSS px。寸法を変える場合は幅・高さのmetaを両方指定します。自動で文章を要約したり、長いページを複数スライドへ分割したりはしません。はみ出しがあれば入力を調整してください。

対応範囲と未対応の表現

JavaScript・イベント属性・外部URLの取得・Webフォント取得・iframe・動画などは受け付けません。React等の実行前のソースではなく、表示内容を静的HTMLにして送ります。外部サイトのURLを渡して変換するAPIではありません。

SVGフィルター、マスク、複雑なクリッピング、3D変形などの未対応表現はエラーで返します。未対応の文字や図解を画像へ置き換えて成功扱いにはしません。一部の細かな描画差はreportの警告で確認できます。

画像のskew・3D変形・clip-path・影、親による切り抜きやfilter、blur以外のfilter、重なる子要素を親のopacityでまとめて透過する表示には対応しません。詳細と指定方法は画像の変形と重なりを参照してください。

表示の完全一致は保証しません。
HTML・SVGの文字はNoto Sans JPに統一して計測・変換します。フォントはPPTXへ埋め込まないため、閲覧端末のフォントで表示が変わることがあります。SVGの文字や図形が編集可能なことと、PowerPointでの表示がブラウザーと完全に一致することは別です。

出力と呼び出し方式

result.zip
├── presentation.pptx
└── report.json

同期HTTPでは既定でZIPを返します。format=pptxを指定するとPPTX本体だけを返します。reportにはスライド数、出力した要素、警告、出力のハッシュなどを記録します。現在は同期HTTPとCLIに対応し、非同期HTTP・Queueからの直接依頼は未実装です。

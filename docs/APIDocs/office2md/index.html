Office → Markdown

概要と変換ルール

Excel・Word・PowerPointの内容を、Markdown・画像・変換情報へ取り出します。

実際の変換例を見る →
複雑な入力を含む変換結果を、スクリーンショットとダウンロードできるファイルで確認できます。

できること

Excel・Word・PowerPointを、文章として扱えるMarkdownと、埋め込み画像・図形の画像に変換します。Java 21 / Apache POIを使う独立したAzure Functionsアプリです。同期HTTP・非同期HTTP・直接Queueは同じ変換コアを利用します。

同期HTTP

ファイルを送信し、その応答でZIPを受け取る。

非同期HTTP

ジョブを登録し、状態を確認して成果物を取得する。

直接Queue

外部システムからBlob参照のJSONを投入する。

旧形式のWord .doc とPowerPoint .ppt、PDF、マクロ有効形式・テンプレート、暗号化ファイルは対象外です。拡張子だけでなく、実際のファイル内容も検査します。

文字・表・変更履歴

本文と表の太字・HTTP/HTTPS/mailtoリンクを保持します。取消線の文字は出力から除去し、リンクや図形altにも復活させません。箇条書きと番号は元の表示を優先し、Markdown閲覧側の再採番を防ぐため番号をエスケープした文字列として出す場合があります。

表は明示ヘッダーがなければ空のヘッダーを追加し、元の全行を残します。Excelでは、検出範囲と有効なExcelテーブル定義が一致する場合だけ先頭行をヘッダーにします。結合セルはアンカーに文字を一度出し、続きは空欄です。Wordの入れ子表など、表現できない構造は文字や警告として残します。

Wordは挿入・移動先を保持し、削除・移動元を除外します。参照された脚注・文末脚注だけを [^footnote-N] / [^endnote-N] として末尾へまとめます。削除された段落記号による段落連結や、結合セルの変更履歴からの構造復元は対象外です。

図形は個別の画像へ

グループの子要素も個別に画像化します。横並び・重なり・接続を理由に一枚へ合成しません。通常のテキストや表はMarkdownに残し、図形内の文字は画像に含めます。図形の文字を本文に二重出力しません。

Excelは長方形・角丸・楕円・線・一部矢印・テキストボックスをJava2Dで近似描画します。Wordの図形文字は代表書式による簡易描画で、図形内リンクの別出力は未対応です。PowerPointはPOIの描画範囲に依存します。グラフ・SmartArt・数式オブジェクトの描画は対象外です。

Excel・Wordの埋め込み画像は原本を取り出し、切り抜き・回転・反転を再現しません。PowerPointでは、回転・切り抜き付きPNG/JPEGを描画画像へ変換します。利用可能な元フォントを優先し、不足時は同梱Noto Sans/Serif・Regular/Boldへ置換します。完全に同じ字幅・改行位置を保証するものではありません。

座標・サイズ・基準の説明

形式座標の意味
Excelシート左上。セルの幅・高さから算出するため、Excelの表示と丸めの差が出る場合がある
PowerPointスライド左上
Word本文内のローカル座標と、浮動図形の水平・垂直基準・保存オフセットを区別する。ページ絶対位置は未算出

右がXの正、下がYの正、単位はpt（1/72インチ）、小数3桁まで表示します。外接矩形は回転・反転・グループ変形後の範囲で、線幅やPNGの余白は含みません。回転前の寸法やPNGのピクセル数とは別です。不明な位置は仮の0座標で補わず「不明」「未算出」とします。説明は保存値から定型生成し、LLMやOCRは使いません。

座標は説明用です。MarkdownやPlaygroundは画像を文書の流れに並べるため、元資料の横並び・重なり・回り込みを再現しません。Excelで表と重なる図形は表の後、Wordは本文XML順に配置します。

数式・外部参照は実行しない

Excelの数式は関数名にかかわらず再計算しません。保存済みの値があれば古い値やエラーもそのまま扱い、欠落を外部取得で補いません。XLSXでキャッシュがなければ式をエスケープして残し、FORMULA_CACHE_MISSING を記録します。式全体が IMAGE(...) なら画像を取得せず未対応表示にします。

外部画像・外部ブック・データ接続を取得／更新せず、WordのフィールドやPowerPointのリンクも実行しません。許可された通常リンクは、閲覧者がクリックした時だけ開きます。Queue・Blobへの通信は管理者が設定したStorage接続で行います。元ファイルをOffice等で開いた時の動作は、そのアプリ側のものです。

Playground と関連資料

ローカル既定URLは http://localhost:7072/api/playground です。匿名で画面を開けますが、Azureの変換APIにはホストキーが必要です。入力HTMLを実行せず、画像は成果物内だけを表示します。「待機を停止」は通信の停止であり、ジョブのキャンセルではありません。

# 条件別の対応を表で比較

区分・条件・担当・処理を1行ずつ対応付けます。結合行の値は開始セルに保持します。

|  |  |  |  |
| --- | --- | --- | --- |
| 区分 | 条件 | 担当 | 処理 |
| 通常 | 資料あり | 受付 | 当日確認 |
| 差戻し | 添付不足 | 申請者 | 再提出 |
| 共通の補足 |  | 管理者 | 期限は営業日 |
| 例外 | 期限超過 | 責任者 | 翌朝判断 |

補足：差戻し後は同じ申請番号で再判定します。

PPT / PPTX / PDF → PNG / JPEG

PowerPoint・PDFを画像へ

ファイルを受け取り、ページ単位で画像化します。同期HTTP、非同期HTTP、外部システムからの直接Queue依頼が、同じ変換処理と上限を使います。

呼び出し方を選ぶ

同期HTTP

POSTのレスポンスで画像またはZIPを受け取ります。アプリ用Storageの設定は不要です。

非同期HTTP

ファイルをPOSTしてジョブIDを受け取り、状態と結果を別のAPIで取得します。

直接Queue

入力をBlobへ保存し、JSONで依頼します。入出力Storageと、ZIP／個別画像の保存を指定できます。

非同期HTTPと直接Queueには CONVERSION_STORAGE_CONNECTION_STRING の設定が必要です。Playgroundを使わずに、外部システムだけで連携できます。

対応するファイル

入力変換処理出力
PowerPoint .pptx / .pptApache POIでスライドを描画PNGまたはJPEG
PDF .pdfPDFBoxでページを描画PNGまたはJPEG

形式は入力内容から判定します。filename の拡張子だけを変更しても、別形式のファイルを変換できるようにはなりません。暗号化されたファイルは対象外です。

これは画像化のAPIです。Markdown、OCR結果、編集可能な図形、変換レポートの生成は契約にありません。出力の背景は白です。

ページ指定なしは、入力が1ページでもZIPです。 page=1 を明示した場合に画像1枚を返します。images モードの結果取得APIは画像一覧のJSONを返し、画像本体はBlobから取得します。

画像の寸法

width を省略すると、元のページの物理寸法を96dpiで画像化します。PowerPointの幅10インチ・高さ7.5インチは960×720pxです。PDFはページごとのCropBox、90度／270度の回転、UserUnitを反映します。

width を指定した場合だけ、横幅をそのピクセル数に合わせ、縦横比を保って高さを決めます。各辺は整数ピクセルへ丸めます。ページごとにサイズが違うPDFも処理できます。

描画前に1ページ当たりの画素数を検査します。幅・高さが大きいページは、ファイル容量が小さくても上限エラーになる場合があります。上限の一覧を参照してください。

出力名とZIPの中身

指定例出力名内容
filename=slides.pptxslides.zippage-0001.png、page-0002.png、…
filename=slides.pptx&page=2slides-page-0002.png2ページ目のPNG
filename=slides.pptx&format=jpegslides.zippage-0001.jpeg、page-0002.jpeg、…
直接Queueの個別画像保存page-0002.png など元のページ番号を保持。ファイル名の前置きなし

ZIP名と単一画像名は、入力名の末尾の拡張子を除き、英数字・_・- 以外を _ に置換して作ります。元の名前部分は最大100文字です。HTTPで名前を省略した場合は document が使われます。JPEGの拡張子は .jpeg です。

描画と日本語フォント

POIの描画はPowerPoint本体と完全には一致しません。元のフォントが利用できる場合、またはPDFにフォントが埋め込まれている場合は、そのフォントを優先します。不足する日本語フォントは、同梱のNoto Sans CJK JP／Noto Serif CJK JPのRegular・Boldで補います。

代替フォントによって文字幅や改行位置が変わることがあります。PDFの代替は日本語として識別できる対象フォント向けで、失われた文字コード情報を復元する機能ではありません。

GET /api/playground — 操作画面

GET/api/playground

匿名で取得できる簡易UIです。同期／非同期、PNG／JPEG、全ページ／1ページを選べます。画像幅は元寸法から自動設定します。末尾に / が付くURLは、末尾なしのパスへ302で移動します。

ローカル起動の既定URLは http://localhost:7071/api/playground です。キーは画面のメモリで保持し、URLやブラウザの永続ストレージへ保存しません。

GET /api/playground/assets/{name} — 静的ファイル

GET/api/playground/assets/{name}

匿名で style.css と app.js を配信します。それ以外の名前は404です。独立したフロントエンドサーバーは必要ありません。

GET /api/playground/config — 公開設定

GET/api/playground/config

認証なしで、次の3項目だけを返します。接続文字列・Storageの登録名・キーは含みません。

{
  "asyncEnabled": false,
  "maxInputBytes": 20971520,
  "maxPages": 50
}

この機能に /api/capabilities はありません。公開設定はすべての上限や対応形式を列挙するAPIではありません。

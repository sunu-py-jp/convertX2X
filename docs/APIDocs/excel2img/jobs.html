非同期HTTP・成果物取得

ファイルを登録してジョブIDを受け取り、完了後に結果を取得します。Storage設定時だけ有効です。

登録

curl --fail-with-body \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @sample.xlsx \
  'http://localhost:7076/api/jobs?filename=sample.xlsx&format=pdf'

描画オプションは同期HTTPと共通です。受付応答のjobIdで状態を確認します。

取得API

GET内容
/api/jobs/{id}状態・エラー。失敗時の範囲理由はerrorDetails
/api/jobs/{id}/result完成結果のZIP
/api/jobs/{id}/archive同じZIP
/api/jobs/{id}/report変換レポート
/api/jobs/{id}/files/pages/page-001.pngPNG単体
/api/jobs/{id}/files/document.pdfPDF単体

完了と部分変換

全成果物を保存してから成功を公開します。ジョブが成功していても、一部の範囲が見送られている場合があります。reportのoutcomeと範囲ごとの結果を確認してください。全範囲見送りは失敗となります。

取得できるのは当該ジョブのmanifestに登録された成果物だけです。任意のBlobパスを指定して読むことはできません。

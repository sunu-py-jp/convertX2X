変換時の注意事項（3件）
  • RANGE_SCALED：文字サイズまたは画像の縮小下限を保つ倍率で縮小しました。横幅を超える部分はページに分割します。
  • HORIZONTAL_PAGINATION：文字や画像の縮小を抑え、列の境目を優先して横方向にも分割しました。ページ順は上段の左から右、その次の段の左から右です。
  • FONT_SUBSTITUTED：セルのフォントは同梱の BIZ UDPゴシックで代替しました。文字幅は原本と異なる場合があります。

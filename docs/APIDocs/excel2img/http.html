Excel → 画像・PDF

同期HTTPで変換

XLSXまたはXLSの生バイト列を送信し、描画結果のZIPを受け取ります。

POST/api/convert

パラメーター

クエリ値
filename拡張子を含む入力名。必須
formatpng（既定）またはpdf
sheetシート名。省略時は表示シート全体
rangeA1:L30など有限の矩形。指定時はsheet必須

入力はContent-Type: application/octet-stream。Azureではx-functions-keyを付けます。multipart・Base64ではありません。

呼び出し例

curl --fail-with-body \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @sample.xlsx \
  'http://localhost:7076/api/convert?filename=sample.xlsx&format=png' \
  --output rendered.zip

PDFはformat=pdfに変更します。シート名・セル範囲はURLエンコードしてください。PDFでも応答はZIPです。

結果の確認

ZIPにはpages/page-001.pngなどのPNG群、またはdocument.pdfとreport.jsonが入ります。reportの範囲とページ対応、見送り理由、警告を確認してから画像・PDFを利用します。

部分的に変換できればHTTP 200です。全範囲を見送った場合は422 NO_RENDERABLE_RANGEで、JSONのdetailsに理由が入ります。

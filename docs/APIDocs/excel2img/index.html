Excel → 画像・PDF

配置を保って、Excelを画像へ。

セル・貼り付け画像・基本図形を同じページへ描画し、PNGまたはPDFとしてLLMへ渡せます。

小さくしすぎない変換。
印刷範囲を優先し、文字を小さくしすぎない倍率まで縮小します。収まらない分は横方向にも分割します。描画には近似を含み、Excelの完全な印刷再現ではありません。

反映するもの

要素扱い
セル値、列幅、行高、結合、背景色、罫線、配置、折り返し、日本語
埋め込み画像セル座標と同じ位置に描画。対応画像はサイズ・回転・切り抜きを反映
基本図形矩形・楕円・ひし形・矢印・線・文字などを近似描画
数式保存済みの結果。再計算や外部データ取得はしない

範囲とページ

  1. 明示したsheetとrange。
  2. シートに保存された印刷範囲。複数なら個別に処理。
  3. 値や描画要素のある範囲。

シート指定なしでは表示シートが対象です。非表示行・列を除き、縦・横ともページに分けます。まず横幅に合わせて縮小し、セル文字が既定12pxを下回る場合は、その下限の倍率で横に分割します。ページ順は上段の左から右、その次の段の左から右です。元から小さい文字は拡大せず警告を残し、文字がない範囲は設定解像度の50%まで縮小します。見出しの繰り返しは行いません。

結果

# PNGの場合
pages/page-001.png
pages/page-002.png
report.json

# PDFの場合
document.pdf
report.json

同期HTTPはどちらもZIPです。PDFには同じ描画画像を使い、描画したセルの文字を検索用に重ねます。図形と重なるセル文字は、見た目で隠れた情報が検索結果に出ないよう検索用文字層から除外し、警告を残します。画像内の文字や図形の文字はOCRしません。非同期では各ファイルをBlobへ個別保存します。

見送りや未対応要素があればreportのoutcomeがpartialになります。全範囲を見送ると422を返します。

再現範囲

フォント置換、折り返し、図形などはExcelと差が出ます。グラフ、SmartArt、特殊な描画要素、条件付き書式、印刷余白やヘッダー／フッターの完全再現は対象外です。警告と実際の画像を確認してください。可読性判定はセル文字の幾何学的な基準であり、元画像内の小さな文字までは判定しません。

Movie → Audio

HTTPS URLから抽出

事前に許可したホストの直接ファイルURLを送り、取得した動画からAACを抽出します。

URL入力を有効にする

Function Appの環境変数に取得先ホストを設定します。未設定・空値ではURL入力を無効にし、503 URL_FETCH_DISABLED を返します。アップロードAPIは引き続き利用できます。

CONVERSION_URL_ALLOWED_HOSTS=media.example.com,exampleaccount.blob.core.windows.net

ホスト名はサブドメインを含めて完全一致です。ワイルドカード・IPアドレス・スキーム・パスを含めず、最大32件をカンマで区切ります。example.com の設定だけでは media.example.com へのアクセスは許可されません。

POST /api/convert-url

POST/api/convert-url
{
  "url": "https://media.example.com/videos/sample.mp4"
}
項目仕様
Content-Typeapplication/json が必須
url空でない文字列。最大8192文字。先頭・末尾の空白は不可
JSON全体最大16KiB。url以外のキー、重複キー、複数のJSON値を拒否
認証Azureでは x-functions-key が必要

curl の例

curl --fail-with-body \
  -H 'Content-Type: application/json' \
  --data-binary '{"url":"https://media.example.com/videos/sample.mp4"}' \
  'http://localhost:7073/api/convert-url' \
  --output audio.m4a

Azureでは呼び出し先をFunction AppのURLへ置き換え、キーをヘッダーで渡します。返却形式はファイル入力と同じ audio.m4a です。取得・抽出を完了したファイルをHTTPストリームで送信します。レスポンスの全ヘッダーを参照してください。

抽出結果をBlobへ直接保存する場合は、入力URLと出力先SASを /convert-to-blob へ送ります。この /convert-url APIは引き続き音声ファイルを返します。

受け付けるURL

条件扱い
HTTPS / 443番ポート必須。ポートの省略と明示的な443を許可
URL内のユーザー名・パスワード / #fragment拒否
署名付きクエリ利用可能。URL自体を秘密情報として扱う
リダイレクト追跡しない。最終的な直接ファイルURLを指定
圧縮レスポンスContent-Encodingは未指定またはidentityのみ
Webページ・再生リスト動画ファイルの取得APIではないため対象外
Cookie・任意の認証ヘッダー指定機能なし。クライアント側のCookieやFunctionキーを取得先に転送しない

外部取得の境界

許可ホストをDNSで解決し、結果の全IPが公開インターネットのアドレスであることを検査します。内部・ループバック・リンクローカル・予約済みアドレス、Azureのプラットフォーム用アドレスなどを拒否します。検証したIPを使って接続します。

取得処理はプロキシ・Cookie・自動リトライを利用せず、実際に読み取るバイト数を入力上限までに制限します。URL本文の受信・動画の取得・抽出・HTTP応答へのファイル読み出しは合算で既定180秒です。サイズ検証後も際限なくリモートのボディを読み捨てることはありません。

FFmpegにはURLを渡さず、取得済みの一時ファイルだけを渡します。同梱FFmpegのネットワーク機能も無効です。アプリのエラーやログには入力URLや署名情報を出しません。

URLに関するエラー

HTTPcode対処
400INVALID_URL_REQUESTJSONの形・url文字列・余分なキーを確認
400INVALID_URLHTTPS、443、URL内認証、フラグメント、文字列長を確認
403URL_HOST_NOT_ALLOWED管理者が許可したホストの直接URLを使用
403URL_ADDRESS_NOT_ALLOWED取得先が公開IPに解決されるか確認
413REQUEST_TOO_LARGE / INPUT_TOO_LARGEJSONは16KiB以下、動画は設定した入力上限以下にする
415JSON_BODY_REQUIREDContent-Typeをapplication/jsonにする
422URL_REDIRECT_NOT_ALLOWEDリダイレクト先の最終URLを使う
422URL_ENCODING_NOT_SUPPORTED取得先から圧縮していないファイル本体を返す
502URL_FETCH_FAILEDDNS・TLS・接続・取得先のHTTP応答を確認。取得先の非200も含む
503URL_FETCH_DISABLEDCONVERSION_URL_ALLOWED_HOSTSを設定
504CONVERSION_TIMEOUT取得・抽出・HTTP応答へのファイル読み出しが期限内に終わる入力を使う

出力ファイルの読み出し中に期限超過やエラーが起きた場合はストリームを中断します。転送中のキャンセルはアプリへ伝搬した時点で処理します。HTTPステータスだけでなく本文の読み取り完了を確認してください。ストリーミングの範囲も参照してください。

取得した動画自体がAAC抽出の条件を満たさない場合は、ファイル入力と同じ変換エラーになります。共通のエラー一覧を参照してください。

ジョブIDを受け取って後から結果を取得する場合は 非同期HTTP、他システムから登録済みBlobを処理する場合は 直接Queue を使います。SAS保存APIは同期専用です。

音声形式の選択は共通の音声オプションを参照してください。URL・SASの本文形式は変更せず、受付URLのクエリで指定します。

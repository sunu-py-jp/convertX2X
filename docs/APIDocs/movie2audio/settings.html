Movie → AAC

設定・上限・エラー

環境変数で入力・出力・処理時間とURLの取得先を指定します。未設定時は100MiB・180秒、ファイル入力のみで動作します。

環境変数

名前既定値意味
CONVERSION_MAX_INPUT_BYTES104857600入力動画の上限100MiB。URL取得にも適用
CONVERSION_MAX_OUTPUT_BYTES104857600出力M4Aの上限100MiB
CONVERSION_TIMEOUT_SECONDS180同期処理、ジョブ受付、Queueの各試行、結果取得にそれぞれ適用する期限。Queue待機は別。1〜210秒
CONVERSION_URL_ALLOWED_HOSTS空完全一致のDNSホスト名をカンマ区切り。空ならURL機能無効
CONVERSION_OUTPUT_ALLOWED_HOSTS空Azure Blobの完全一致ホスト名をカンマ区切り。空ならBlob保存API無効。入力の許可ホストとは独立
CONVERSION_STORAGE_CONNECTION_STRING空制御用Storageの接続文字列。設定すると非同期HTTP・直接Queueを有効化
CONVERSION_INPUT_STORAGE_{NAME}なし追加の入力用Storage接続。登録名の指定
CONVERSION_OUTPUT_STORAGE_{NAME}なし追加の出力用Storage接続。結果APIを使う場合は読み取り権限も必要
AzureWebJobsStorage配置環境で指定Functionsホスト用。非同期機能の有効化とは別
FUNCTIONS_WORKER_RUNTIMEnodeNode.jsワーカーを使用

バイト数は正の整数で 2147483639 以下です。数値設定の未設定・空値は既定値を使い、不正値は起動時に拒否します。許可ホスト設定は最大32件・全体8192文字で、ワイルドカードやIPアドレスは指定できません。

ローカルは local.settings.json の Values、AzureはFunction Appの環境変数へ設定します。アプリの上限を変更しても、Azureホストや前段サービスのボディ上限は自動変更されません。

アップロードを100MiB超へ拡大する場合、ホストの FUNCTIONS_REQUEST_BODY_SIZE_LIMIT（既定 104857600 バイト）も合わせて設定します。ホストが先に拒否した応答は本アプリのJSON形式ではありません。既定値の根拠は Microsoft Learn を参照してください。Node.jsのHTTPストリーミングはアプリ起動時に有効にしています。

実行環境と同時処理

項目仕様
ランタイムNode.js 22 / 24、Functions v4モデル。同梱FFmpeg / FFprobe 9.0.1
対応環境Linux x64（静的muslビルド）、macOS Apple Silicon
Node.jsプロセス内同期処理・非同期受付・Queue処理・結果取得で共有する実行枠は1件。HTTP競合は503 CONVERSION_BUSY、Queue競合は再試行
host.jsonHTTP同時実行1件、待機込み8件、functionTimeout 4分。QueueはbatchSize 1、newBatchThreshold 0、maxDequeueCount 10、visibilityTimeout 1分。動的同時実行は無効
実際のアプリ期限既定180秒。共通の単一期限で入力受信・URL取得・解析・コピー・HTTP応答へのファイル読み出し、またはBlob保存完了を制限
保存OSの一時ディレクトリ。完成済みM4Aをストリームで返し、ファイル読み取りストリームが閉じたときに削除
Storage / Queue同期SAS保存と、登録接続を使う非同期は別の経路。非同期のQueueと制御コンテナーはmovie2audio-jobs。入出力・状態の保持期間は運用側で設定

出力ファイルの読み出し完了は、クライアントの受信完了を意味しません。その後にSDK・ホストのバッファから転送されるデータは、アプリの180秒タイマーの対象外です。転送中のキャンセルはアプリへ伝搬した時点で処理します。

プロセス内の同時実行制御は複数インスタンス全体の制御ではありません。スケールアウト時は各インスタンスで並列に処理できます。functionTimeout はHTTP接続の維持時間や所要時間を保証しません。

FFmpegは起動時にダウンロードせず、同梱ファイルのチェックサムを確認して所有者のみ利用可能な一時ディレクトリへ展開します。ユーザーがFFmpegの引数や実行パスを指定するAPIはありません。

GET /api/capabilities

GET/api/capabilities

GET /api/playground/config も同じ公開設定JSONを返します。以下は既定値です。どちらも匿名で、許可ホスト一覧・キー・接続情報は返しません。

{
  "urlEnabled": false,
  "asyncEnabled": false,
  "maxInputBytes": 104857600,
  "maxOutputBytes": 104857600,
  "timeoutSeconds": 180,
  "outputFormat": "m4a",
  "audioCodec": "aac",
  "audioMode": "copy"
}

公開設定には asyncEnabled を追加しています。登録StorageやSAS保存先の一覧は含めません。

urlEnabled は入力許可ホスト設定、asyncEnabled は制御用Storage接続設定の有無を示します。取得先への接続やFFmpeg実行のヘルスチェックではありません。

Playgroundの公開エンドポイント

GETパス内容

上記以外のアセット名は404です。変換・ジョブ受付・状態・結果APIはFunction認証、画面と公開設定は匿名です。既定のパス接頭辞は /api で、host.json のルート設定を変更した場合は読み替えます。

Playgroundは同期／キュー実行を選択でき、非同期は3秒おきに状態を確認して音声を取得します。画面の待機上限は15分で、受付済みジョブの期限やキャンセルを変更しません。

エラーレスポンス

{
  "error": {
    "code": "INPUT_TOO_LARGE",
    "message": "The video exceeds the input size limit."
  }
}

送信開始前のアプリ由来のエラーは error.code と error.message を持ちます。HTTPステータスとコードで判定してください。Azureホストの認証・容量・タイムアウトエラーはこの形式と異なる場合があります。

HTTPcode原因
400EMPTY_INPUTリクエストや取得動画が空
400INVALID_CONTENT_LENGTHContent-Lengthが非負の整数ではない
400INVALID_URL_REQUEST / INVALID_URLURL JSONまたはURL構文が不正
403URL_HOST_NOT_ALLOWED / URL_ADDRESS_NOT_ALLOWED許可外ホストまたは公開IPではない取得先
413INPUT_TOO_LARGE / OUTPUT_TOO_LARGE設定した動画入力・M4A出力の上限超過
413REQUEST_TOO_LARGEURL JSONは16KiB、Blob保存JSONは32KiB、multipartのJSONファイルは16KiBを超過。multipart全体にも入力上限 + 64KiBの制限あり
415RAW_BODY_REQUIRED / JSON_BODY_REQUIRED入力APIに合わないContent-Type
422NO_VIDEO_STREAM / NO_AUDIO_STREAM動画または音声ストリームがない
422UNSUPPORTED_AUDIO_CODEC最初の音声トラックがAACではない
422INVALID_MEDIA / EMPTY_OUTPUT未対応・破損ファイル、抽出失敗、空の成果物
422URL_REDIRECT_NOT_ALLOWED / URL_ENCODING_NOT_SUPPORTEDリダイレクトまたは圧縮レスポンス
500STORAGE_ERROR / OUTPUT_MISSING / INTERNAL_ERROR一時ファイルや処理内部の問題
502URL_FETCH_FAILED取得先の非200応答、DNS・TLS・接続エラーなど
503URL_FETCH_DISABLEDURL許可ホスト未設定
503CONVERSION_BUSY同じNode.jsプロセスで別の処理または送信が実行中
503FFMPEG_UNAVAILABLE非対応環境や同梱バイナリ準備・実行の問題
504CONVERSION_TIMEOUT入力受信からHTTP応答へのファイル読み出し、またはBlob保存完了までの共通期限超過

ジョブAPIのエラーと状態の読み方は 非同期HTTP、再試行・poison・重複配送は 直接Queue を参照してください。状態APIでは failed も正常なJSON応答です。

子プロセスの待機中に実行が中断された場合は 503 CONVERSION_INTERRUPTED です。503には Retry-After: 3 を付けます。CONVERSION_BUSY は時間を空けて再試行できますが、設定不足や実行環境の問題は修正が必要です。URL固有の対処も参照してください。

レスポンス送信開始後のエラーはJSONでは返せません。出力ファイルの読み出し中の期限超過やエラーではストリームを中断します。利用側は応答本文の正常終了も確認します。返却方法の詳細を参照してください。

Blob保存固有のエラー、受け付けるSASと再試行時の扱いも参照してください。

ビルドと保守

cd functions/movie2audio
npm ci
npm test
npm run package

dist/ に実行用ソース・アセット・本番用依存とFFmpegのソース・ライセンス一式を作成します。配置先はLinux x64 / Node.js 24の独立したFunction Appです。ビルド・テストはAzureへ公開しません。FFmpegの再ビルド、ソース・ライセンス・manifestの管理は 同梱FFmpegのREADMEを参照してください。アプリのMITライセンスと同梱FFmpegのライセンスはそれぞれ保持します。

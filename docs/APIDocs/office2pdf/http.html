Office → PDF

同期HTTPで変換

ファイルのバイト列をPOSTし、PDFを直接受け取ります。

POST /api/convert

POST/api/convert?filename=input.xlsx

filenameは元の拡張子を含めます。本文はmultipartではなくapplication/octet-streamの生データです。

curl --fail-with-body \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @input.xlsx \
  'http://localhost:7074/api/convert?filename=input.xlsx' \
  --output document.pdf

成功レスポンス

項目値
Status200 OK
Content-Typeapplication/pdf
Content-Disposition入力名を基にした.pdf
X-Page-Count生成PDFのページ数
X-Section-Countシート・文書・表示スライド数
X-Warning-Count近似・除外の警告数

Azureでの認証

Azure上ではx-functions-keyヘッダーを付けます。ローカルCore Toolsでは通常キーは不要です。

curl --fail-with-body \
  -H "x-functions-key: $FUNCTION_KEY" \
  -H 'Content-Type: application/octet-stream' \
  --data-binary @slides.pptx \
  'https://<app>.azurewebsites.net/api/convert?filename=slides.pptx' \
  --output slides.pdf

主なエラー

HTTPcode意味
400EMPTY_INPUT / MISSING_FILENAME入力またはファイル名がない
413INPUT_TOO_LARGE / PAGE_LIMIT / OUTPUT_BYTES_LIMIT設定上限を超えた
415UNSUPPORTED_FORMAT / ENCRYPTED_DOCUMENT対象外または暗号化
422INVALID_DOCUMENT / SLIDE_RENDER_FAILED文書を読めない、描画できない

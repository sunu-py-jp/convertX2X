Office → PDF

実際の変換例

実装した変換コアで生成したExcel入力・PDF・reportをそのまま確認できます。

左右の関連列を一つの表へ

入力Excelは、通常表の右側に空列を挟んで「担当」「補足」を置いています。変換では値のある列を詰め、同じ行の関連情報を一つの検索可能な表としてPDFへ配置します。2つ目の「概要」シートを含むため、PDFは2ページです。

input.xlsx

2シートの入力ブックをダウンロード

document.pdf

実変換した検索可能PDFを開く

report.json

ハッシュ、ページ数、警告を確認

reportの結果

{
  "sectionKind": "sheet",
  "sectionCount": 2,
  "output": {"path":"document.pdf","pageCount":2},
  "warnings": []
}
この例はOfficeの印刷画面の再現ではなく、Document Intelligenceが文字と表を読み取りやすい配置への正規化を確認するものです。

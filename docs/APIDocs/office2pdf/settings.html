Office → PDF

設定・上限・エラー

内容の個数制限は既定で置かず、実メモリと応答サイズに関係する境界を設定します。

変換上限

環境変数既定説明
CONVERSION_MAX_INPUT_BYTES20 MiBHTTP・Blob入力
CONVERSION_MAX_OUTPUT_BYTES100 MiBPDF、report、ZIPの出力境界
CONVERSION_MAX_PAGES0生成PDFページ。0は無制限
CONVERSION_MAX_IMAGE_PIXELS20,000,0001画像・1スライド描画の画素数

シート、セル、行・列、段落、表、スライド、図形の個数に独立した上限はありません。PowerPointは画素上限に収まるよう描画解像度を下げます。Excel・Wordの大きすぎる画像は警告を残して省略します。

非同期Storage

設定用途
CONVERSION_STORAGE_CONNECTION_STRING制御用Blob・Queue。空なら非同期無効
CONVERSION_STORAGE__blobServiceUriManaged Identity用Blob URL
CONVERSION_STORAGE__queueServiceUriManaged Identity用Queue URL
CONVERSION_STORAGE__clientIdユーザー割当IDの任意client ID
CONVERSION_CREATE_RESOURCESコンテナー・Queueの自動作成。既定true

メモリ保護

host.jsonのHTTP同時実行数とQueueバッチは1です。変換コアもセマフォで1件ずつ処理します。複数件はFunctionsのインスタンススケールで並列化します。

公開設定

GET/api/capabilities

対応拡張子、同期・非同期の有効状態、4つの上限をJSONで返します。資格情報は返しません。

エラー応答

{"error":{"code":"UNSUPPORTED_FORMAT","message":"..."}}

上限超過は主に413、対象外形式は415、壊れた文書や描画失敗は422、非同期未設定は503です。内部例外・接続文字列・入力内容は応答へ出しません。

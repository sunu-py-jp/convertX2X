# Excel → 画像・PDFの実装

`functions/excel2img/` は独立したJava 21 Function Appです。
セルと埋め込み画像の位置関係を残し、PNGやPDFをそのままLLMへ渡す用途を扱います。
`office2md` の表検出やMarkdown変換、`office2pdf` の表の再配置は利用しません。

## 処理

1. `RenderOptions` が出力形式・シート・有限セル範囲を検証。
2. `ExcelImageService` がPOIでXLSX/XLSを開く。
3. 明示範囲、印刷範囲、内容の範囲の順で描画対象を決定。
4. 列幅・行高・非表示設定から、シート上の座標を計算。
5. 横幅・最小文字サイズ・全描画範囲の合計セル数を検査し、見送り理由を記録。
6. 縦方向にページを割り、セルと `ExcelDrawingLayer` を同じ座標系で描画。
7. PNGまたはPDFを一時ディスクへ書き、reportとともに返す。

HTTPとQueueは同じサービスを呼びます。既定2048×2800px以内、2px/pt、最小文字サイズ12pxです。
長大な横長表を強制的に縮小しません。印刷範囲の設定は範囲選択として扱い、Excelの
用紙・余白・印刷倍率・ヘッダー／フッターまで再現する機能ではありません。

## 制約と結果の読み方

POIにはExcelをそのまま描画するエンジンがないため、この機能でJava2Dによる描画を実装しています。
対応するセル・図形は近似描画です。日本語は同梱フォントを使用し、外部参照は取得しません。
複雑なグラフや未対応要素は警告を残すため、`report.json` を変換結果と一緒に確認します。

一部見送り・未対応要素があれば `outcome: "partial"`。全範囲見送りは
`NO_RENDERABLE_RANGE` の422です。文字サイズの検査はOCRではなく、元の文字サイズと縮小率の計算です。
元画像の中の文字はこの判定に含まれません。

## 変更・検証

- レイアウトの変更は、結合・隠し行列・印刷範囲・横長見送り・縦分割の回帰を確認します。
- 描画の変更は、日本語、画像の位置、矢印、回転、クロップ、未対応要素の警告を確認します。
- 範囲や出力オプションの追加は、HTTP、Queue JSON、重複依頼の比較、report、Playgroundも更新します。
- 資源上限は画像の展開・ビットマップ確保の前に検査し、一時ファイルは失敗時も削除します。
- 外部リンクや数式の接続先にはアクセスしません。保存済み数式値を利用します。
- ライセンス原文の検証と同梱を含め、`./mvnw clean package` を通します。

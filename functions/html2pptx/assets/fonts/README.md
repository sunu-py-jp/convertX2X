# Noto Sans JP

This directory contains static TrueType instances of **Noto Sans JP**, not Noto Sans CJK JP.

| File | Family | Style / weight |
| --- | --- | --- |
| `NotoSansJP-Regular.ttf` | Noto Sans JP | Regular / 400 |
| `NotoSansJP-Bold.ttf` | Noto Sans JP | Bold / 700 |

The instances were generated from the pinned official Google Fonts variable font. No glyphs were subsetted. The original copyright and SIL Open Font License 1.1 are preserved in `OFL.txt` and in the font name tables.

Source URLs, hashes, version, generation details and the reproducible maintenance script are in [the font provenance directory](../../third-party/fonts/noto-sans-jp/README.md). Keep those records and the OFL with standalone distributions.

These files are used by the conversion browser and developer previews. They are not embedded into generated PPTX files. FontTools/Python are only needed to reproduce the checked-in static instances; production conversion does not invoke them.

# Bundled font

`BIZUDPGothic-Regular.ttf` and `BIZUDPGothic-Bold.ttf` are unchanged static
TrueType files from the official Google Fonts Morisawa BIZ UDGothic repository,
pinned to commit `18934af56b9c003ca58c54bffbf226848cb11032`:

<https://github.com/googlefonts/morisawa-biz-ud-gothic/tree/18934af56b9c003ca58c54bffbf226848cb11032/fonts/ttf>

They are bundled so Japanese PDF text remains searchable and rendering does not
depend on fonts installed on the Azure Functions host. The fonts are distributed
under the SIL Open Font License 1.1. The unmodified license is included as
`OFL.txt`; file hashes are recorded in `SHA256SUMS`.

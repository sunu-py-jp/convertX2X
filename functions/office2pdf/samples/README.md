# 実変換サンプル

`excel-normalized/` は実装した変換コアで生成したExcel変換例です。

| ファイル | 内容 |
| --- | --- |
| `input.xlsx` | 通常表の右側に、空列を挟んだ担当・補足列を持つ2シートのブック |
| `document.pdf` | 左右の値を一つの表へ正規化した、検索可能な2ページPDF |
| `report.json` | 入出力SHA-256、ページ数、シート数、警告 |

PDFはOfficeの画面をそのまま印刷したものではありません。表の右側の関連情報を
同じ行の列として取り込み、Document Intelligenceが一つの表として読みやすい形に
しています。
